# CAPY ตัวตึง — Game Design Document v1.0

## Game Overview

Title: CAPY ตัวตึง: The Great Escape

Genre: Story + Open World / Escape / Adventure / Comedy

Style: Stylized 3D Cartoon

Setting: A fictional Thai tropical zoo inspired by
the countryside around Khao Yai.

Difficulty: Medium

Future target: PC, Mobile, Tablet; 1–4 players.

## Core Gameplay Loop

Explore -> Find escape route -> Avoid guards
-> Reach checkpoint -> Complete mission
-> Unlock new area.

## Main Character

A stubborn, lovable capybara escaping from a zoo.

Planned abilities:
- Walk
- Sprint
- Jump
- Hide
- Capy Stare
- Swim

## World Roadmap

Zone 01: Capy Zoo
Zone 02: Outer Road
Zone 03: Village and Market
Zone 04: Forest and Resort

## Mission Development

M01A: Project and zoo foundation
M01B: Environment visual polish
M01C: Capybara controller
M01D: Guard AI
M01E: Three escape routes
M01F: HUD, rewards, saving and QA

## Mission 01 Targets

Duration: 6–10 minutes.

Escape routes:
- Main Gate
- Maintenance Tunnel
- Fence Escape

First-clear reward target: 150 Capy Coins.

Stars: 1–3.

These gameplay systems are not implemented in M01A.
