# Mission 01A Test Plan

## Static Tests

1. Validate default.project.json.
2. Check all source files exist.
3. Check Rojo mapping.
4. Check Luau imports.
5. Run git diff --check.
6. Run rojo build if available.

Automated command from the repository root (Rojo 7.7.1, Luau 0.743 and Python
3.10+ on PATH):

```sh
python3 tests/check_world.py
```

The runner checks the source map generated by Rojo, compiles all four production
scripts and executes the bootstrap/builder in a mocked Roblox data model. It
checks generated geometry, collision flags, spawn clearance, continuous gate
openings, checkpoint visibility and idempotent rebuilding. This is not a Roblox
engine test or Roblox-aware type check.

## Roblox Studio Tests

1. Start a new Baseplate.
2. Delete the default SpawnLocation, connect the Rojo plugin and sync.
3. Press Play.
4. Check Workspace/CapyWorld exists.
5. Verify exactly one generated CapyWorld.
6. Confirm enclosure, pond, walkways and buildings.
7. Confirm perimeter walls and locked gates.
8. Confirm CapySpawn exists.
9. Confirm CP01, CP02 and CP03 exist.
10. Confirm visible geometry and collision.
11. Check Studio Output for script errors.
12. Rebuild and verify no duplicated world.

For the rebuild check, use the **server** Command Bar while Play is running:

```lua
require(game.ServerScriptService.World.ZooBuilder).Build()
```

Run it twice. Confirm exactly one `CapyWorld` and one `CapySpawn` remain; confirm
the three markers are visible (CP01 sits beside the spawn). Test fresh Play
sessions for actual spawn placement and inspect all buildings and fences from
both sides. Check that signs face their intended viewing areas and doorway gaps
are traversable. Use Studio tools to inspect the visitor area beyond the locked
enclosure gate; unlocking gates is outside M01A. Check ground/path collision,
blocked gates and fences, decorative water and markers, and errors in Output.

Current Roblox Studio Playtest status: **NOT RUN**. Headless results must not
change this status.

must be reported separately.

Do not report Roblox Studio PASS
unless the test was actually performed.
